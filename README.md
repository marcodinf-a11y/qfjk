# qfjk

A planned virtual tabletop for a GM and players sharing a LAN session. The GM's desktop hosts the authoritative game state; players join from Windows, Linux, Android, or iOS.

The first playable release targets D&D 5e 2014 with homebrew, character editing and sheets, explanatory ability text, interactive level-up, inventory, conditions, movement, maps, encounters, and dice. Automatic resolution will be configurable globally, by creature type, and by individual creature. Exact scope and implementation choices are being planned.

Character visualization is part of v1. Exploration and web support are later goals; additional RPGs inform the extension design but are not first-release implementations.

## Project status and licensing

qfjk is intended to be open source and is public from the start. Selecting the software license and the separately licensed rules/content/asset distribution policy remains an open planning decision; no project-wide license has been selected yet.
